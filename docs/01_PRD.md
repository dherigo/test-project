# PRD — 현장별 공정·기성 대시보드

## 한눈에 보기

- 본사 공무팀 담당자가 매달 12개 현장의 공정·기성을 한 화면에서 비교하는 PC 웹 앱입니다.
- 줄이고 싶은 불편은 늦어진 현장을 늦게 알아채는 것입니다.
- 첫 화면은 12개 현장 비교표가 중심이고, 점검 현장은 상태 표시와 점검 줄로 먼저 눈에 띄게 합니다.
- CSV는 원본 열에 계산 열을 더해 내보내고, AI는 기록된 상황과 대응 계획을 근거로 설명합니다.
- 성공 기준은 이 문서의 "정답 숫자" 표와 같은 결과가 나오는 것입니다.

> 이 문서의 현장·금액·기록은 모두 교육용 가상 자료입니다. 실제 동일토건의 계약·현장·청구 자료가 아닙니다.

## 1. 누가·언제·왜 쓰는지

| 항목 | 내용 | 근거 |
|---|---|---|
| 누가 | 본사 공무팀 담당자 (질문 1: A) | 매달 현장 자료를 모아 보고하는 일을 합니다. |
| 언제 | 매달 현장 자료를 받은 뒤 | 자료는 한 달에 한 번, 월말 상태로 들어옵니다. |
| 왜 | 12개 현장 중 계획보다 늦어진 곳을 찾고, 그 이유와 대응 계획을 확인하려고 | 자료에 계획 공정률·실제 공정률과 월별 기록이 함께 있습니다. |
| 사용 환경 | PC 브라우저 | 실습조건에서 정한 범위입니다. |

## 2. 줄이고 싶은 불편

| 항목 | 내용 | 근거 |
|---|---|---|
| 가장 먼저 줄일 불편 | 늦어진 현장을 늦게 알아채는 것 (질문 2: C) | 자료에서 점검 현장은 2025-10에 0곳, 2026-09에 3곳(D·I·K)입니다. 늘어나는 동안 한눈에 보이는 곳이 없으면 늦게 알게 됩니다. |
| 해결 방법 | 점검 상태를 가장 눈에 띄게 표시하고, 공정차이가 작은 순으로 보여줍니다. | 공정차이(실제 - 계획)가 -5pp 이하이면 점검입니다. |

## 3. 만들 기능 (필수 기능)

| 번호 | 기능 | 내용 | 근거 |
|---|---|---|---|
| 1 | 자료 가져오기 | CSV 또는 JSON 파일을 검사하고 미리 본 뒤 전체를 바꿉니다. 오류가 있거나 취소하면 지금 자료를 그대로 둡니다. CSV 다음에 JSON을 가져와도 144행입니다. | 잘못된 파일이 들어와도 기존 자료가 망가지지 않아야 합니다. |
| 2 | 현황 보기 | 처음에는 2026년 9월·전체 현장입니다. 월·지역·공사 유형·현장을 고릅니다. 전체 기성률, 계획·실제 공정률, 공정차이를 큰 숫자로 보여줍니다. 선택 월까지의 계획·실제 공정률 추이와 월별 기성 막대도 보여줍니다. | 월별 변화를 함께 봐야 늦어지는 중인지 회복 중인지 알 수 있습니다. 예: D는 8월 -11.2pp에서 9월 -10.7pp로 줄었습니다. |
| 3 | 점검 현장 찾기 | 상태는 점검(-5pp 이하), 주의(-5pp 초과 0pp 미만), 정상(0pp 이상)입니다. 점검 순서는 공정차이가 작은 순이고, 같으면 현장 ID 순입니다. 점검 현장 한 줄에는 계획·실제 공정률, 공정차이, 기성률을 함께 보여줍니다 (질문 4: C). 점검 줄을 누르면 현장별 비교표로 가서 그 줄을 강조하고 기록을 펼칩니다 (질문 5: A). | 한 줄에서 늦어진 정도와 금액 기준 진행을 같이 봐야 현장끼리 비교하기 쉽습니다. |
| 4 | 현장별 비교표 | 12개 현장의 지역·유형·당월 주요 공종·금액·공정·상태를 보여줍니다. 행을 펼치면 공사기간·기록된 상황·대응 계획이 같은 페이지 안에서 열립니다. | 숫자 옆에 기록이 있어야 "왜 늦어졌는지"를 바로 볼 수 있습니다. |
| 5 | CSV 내보내기 | 지금 고른 월·지역·유형·현장과 같은 범위를 내보냅니다. 원본 15개 열에 기성률, 공정차이, 상태, 당월기성액 열을 더합니다 (질문 6: B). 엑셀에서 한글이 깨지지 않게 합니다. | 엑셀에서 다시 계산하지 않아도 되고, 화면과 같은 숫자로 맞출 수 있습니다. |
| 6 | AI에게 묻기 | 계산은 프로그램이 하고 AI는 그 숫자와 기록을 근거로 설명합니다. 주로 점검 이유와 기록된 대응을 묻습니다 (질문 7: A). 자료에 없는 내용(실제 준공일·미수금 등)은 "자료 없음"으로 안내합니다. 필터를 바꾸면 이전 답변을 지웁니다. AI 연결이 실패해도 대시보드와 CSV는 계속 씁니다. | AI가 숫자를 직접 계산하면 틀릴 수 있어서 계산과 설명의 역할을 나눕니다. |

기능 번호는 실습조건의 필수 기능 5개 중 "점검 현장 찾기"의 비교표·펼침 부분을 4번으로 따로 적은 것이어서, 내용은 5개 필수 기능과 같습니다. (AI 결정)

### 이 자료에서 지켜야 할 계산 기준

| 항목 | 기준 | 예시 |
|---|---|---|
| 공정차이 | 실제 공정률 - 계획 공정률 (pp) | D: 75.8 - 86.5 = -10.7pp |
| 기성률 | 누적기성액 / 계약금액 × 100 | D: 50,384.4 / 72,600 = 69.4% |
| 당월기성액 | 이번 달 누적기성액 - 바로 전월 누적기성액 | 9월 전체: 424,063.4 - 395,184.7 = 28,878.7 |
| 첫 달 | 전월 자료가 없으면 "계산 불가". 0이나 누적액으로 대신하지 않습니다. | 2025-10 |
| 당월기성액 0.0 | 누락이 아니라 정상값입니다. | J의 7월 (기성 확인 서류 보완) |
| 자료 없음 | 0%로 바꾸지 않고 "계산 불가"로 표시합니다. | 선택 범위에 자료가 없을 때 |
| 상태 판정 | 공정차이로만 판정합니다. 현장 기록의 특이사항 분류와는 별개입니다. | J는 기록에 "기성 확인"이 있어도 상태는 공정차이로 정해집니다. |
| 표시 | 금액은 백만원, 비율은 소수 첫째 자리 | 67.2%, -2.0pp |

## 4. 화면 구성

| 구분 | 이름 | 담을 내용 |
|---|---|---|
| 페이지 | 현황 요약 (첫 화면) | 필터, 큰 숫자 4개, 점검 줄, 12개 현장 비교표, 선택 월까지의 추이와 월별 기성 막대 |
| 페이지 | 현장별 비교표 | 12개 현장 전체 표와 펼침 행 |
| 페이지 | 자료 가져오기 | 파일 고르기, 검사 결과와 미리보기, 완료 |
| 페이지 | AI에게 묻기 | 지금 범위 표시, 예시 질문, 질문 입력, 답변과 기준 월·현장·근거 숫자·기록 필드 |
| 상태 | 자료 없음 | 처음 열었을 때 |
| 상태 | 가져오기 오류 | 어느 행의 무엇이 문제인지, 지금 자료는 유지된다는 안내 |
| 상태 | 점검 대상 없음 | 고른 범위에 점검 현장이 없을 때 |
| 상태 | AI 답변 기다리는 중 / AI 연결 실패 | 대시보드는 계속 쓸 수 있다는 안내 |

첫 화면 배치 (AI 결정): 위에서부터 필터 → 큰 숫자 4개 → 점검 줄 → 12개 현장 비교표 → 추이와 월별 기성 막대 순입니다. 근거: 비교표가 첫 화면의 중심이면서(질문 3: C), 늦어진 현장을 먼저 알아채야 하므로(질문 2: C) 점검 줄을 비교표 위에 둡니다.

## 화면 요약

1. 페이지 4개: 현황 요약(첫 화면), 현장별 비교표, 자료 가져오기, AI에게 묻기. 상태 5개: 자료 없음, 가져오기 오류, 점검 대상 없음, AI 답변 기다리는 중, AI 연결 실패.
2. 첫 화면 순서: 월·지역·유형·현장 필터 → 큰 숫자 4개 → 점검 줄 → 12개 현장 비교표 → 계획·실제 추이와 월별 기성 막대.
3. 숫자 단위: 금액은 백만원, 비율은 소수 첫째 자리 %, 공정차이는 pp. 첫 달 당월기성액과 자료 없음은 "계산 불가".
4. 상태 구분: 정상(초록)·주의(노랑)·점검(빨강) 배지에 글자를 함께 표시. 기준은 공정차이 0pp 이상 / -5pp 초과 0pp 미만 / -5pp 이하.
5. 점검 줄 한 줄: 현장 ID·이름, 계획 공정률, 실제 공정률, 공정차이, 기성률. 누르면 비교표로 가서 그 줄을 강조하고 기록을 펼침.
6. 비교표: 지역·유형·당월 주요 공종·계약금액·누적기성액·공정·상태. 펼침 행에 공사기간·기록된 상황·대응 계획.
7. CSV: 원본 15열 + 기성률(%)·공정차이(pp)·상태·당월기성액(백만원).
8. AI 예시 질문: "D가 늦어진 원인과 대응은?", "점검 현장은 어디인가요?", "J의 7월 기성은 왜 늘지 않았나요?"
9. 예시 숫자(2026-09 전체): 기성률 67.2%, 계획 73.2%, 실제 71.2%, 공정차이 -2.0pp. 점검 D -10.7pp(계획 86.5%·실제 75.8%·기성률 69.4%), I -7.6pp, K -5.4pp.
10. 모든 현장명은 가상이며 실제 회사의 자료가 아님을 화면 하단에 표시.
