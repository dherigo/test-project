# FRD — 현장별 공정·기성 대시보드

## 한눈에 보기

- 화면 4개(현황 요약·현장별 비교표·자료 가져오기·AI에게 묻기)에서 무엇을 누르면 어떻게 동작하는지 기능 16개로 정리했습니다.
- 월·지역·유형·현장 필터 4개는 숫자·추이·비교표·CSV·AI에 모두 같은 범위로 적용됩니다.
- 누적값(누적기성액·공정률)과 당월기성액은 따로 계산합니다. 당월기성액은 바로 전월이 있을 때만 구하고, 첫 달(2025-10)은 "계산 불가"입니다.
- 비교표 행을 펼치면 공사기간·기록된 상황·대응 계획이 같은 페이지 안에서 열리고, 점검 줄을 누르면 그 행이 강조되어 펼쳐집니다.
- 오류는 어디가 문제인지 보여 주고 지금 자료를 유지합니다. AI가 실패해도 대시보드와 CSV는 계속 씁니다.

> 모든 현장명·금액·기록은 교육용 가상 자료입니다. 계산과 숫자는 `data/데이터설명.md`와 `data/검산표.md`를 따릅니다.

| 시안의 숫자 | 시안 속 현장명·지역·금액·기성액(예: 서울 현장, 34,812백만원, -8.8pp)은 자리 표시용입니다. 앱은 `data/` 자료로 계산한 값만 보여줍니다. |

## 1. 기능별 표

필터 4개(월·지역·유형·현장)와 "필터 범위"라는 말은 모든 행에서 같은 뜻입니다: 지금 고른 월·지역·유형·현장입니다.

| 번호 | 기능 | 사용자가 하는 일 | 프로그램이 하는 일 | 화면에 보이는 결과 | 오류·예외일 때 |
|---|---|---|---|---|---|
| F1 | 기준 월 선택 | 상단 "기준 월" 목록에서 월을 고릅니다. | 자료에 있는 월만 목록에 넣습니다. 고른 월로 모든 지표를 다시 계산합니다. 추이는 시작 월~선택 월까지만 그립니다. | 큰 숫자·점검 줄·비교표가 그 월 값으로 바뀝니다. 예: 2026-08 → 기성률 62.7%. | 선택 범위에 그 월 행이 없으면 "선택 범위 자료 없음"을 보여주고 0%로 바꾸지 않습니다. |
| F2 | 지역 선택 | "지역" 목록에서 인천·경기·충남·충북·세종·강원·대전 또는 전체를 고릅니다. | 지역에 맞는 현장만 남기고 전체 화면을 다시 계산합니다. 현재 고른 현장이 새 범위에 없으면 현장을 "전체"로 되돌립니다. | 예: 2026-09 인천 → A·G 2곳, 기성률 61.2%. | 지역과 유형 조합에 현장이 없으면(예: 강원·물류시설) "선택 범위 자료 없음"을 보여줍니다. |
| F3 | 공사 유형 선택 | "공사 유형" 목록에서 공동주택·물류시설·업무시설·상업시설·생산시설 또는 전체를 고릅니다. | F2와 같습니다. 지역과 유형은 함께(그리고) 적용합니다. | 예: 2026-09 인천+공동주택 → A·G 2곳. | F2와 같습니다. |
| F4 | 현장 선택 | "현장" 목록에서 현장 하나 또는 전체를 고릅니다. 목록에는 지금 지역·유형 범위에 있는 현장만 나옵니다. | 그 현장 1곳으로 전체 화면을 다시 계산합니다. | 예: 2026-09 D → 기성률 69.4%, 비교표 1행, 추이는 D만의 12개월. | 선택 현장이 지역·유형 변경으로 범위에서 빠지면 "전체"로 되돌리고, 화면에 "현장 선택을 전체로 바꿨습니다"라고 한 줄 알려줍니다. |
| F5 | 필터 초기화 | "필터 초기화"를 누릅니다. | 월은 2026-09(자료에 없으면 자료의 가장 최근 월), 지역·유형·현장은 전체로 되돌립니다. AI 답변도 지웁니다. | 2026-09 전체: 기성률 67.2%, 점검 D·I·K. | 자료가 없으면 버튼을 눌러도 바뀌는 것이 없고 "자료 없음" 상태가 유지됩니다. |
| F6 | 큰 숫자 4개 보기 | (보기만 합니다. 필터를 바꾸면 값이 바뀝니다.) | 필터 범위의 전체 기성률, 가중 계획 공정률, 가중 실제 공정률, 공정차이를 계산합니다. 기성률 카드 아래에 "누적 기성액 / 계약금액"을 함께 씁니다. | 2026-09 전체: 67.2% (424,063.4 / 630,700백만원), 계획 73.2%, 실제 71.2%, 공정차이 -2.0pp. 공정차이에는 상태 글자와 색을 함께 표시합니다. | 범위에 자료가 없거나 계약금액 합계가 0이면 네 숫자 모두 "계산 불가"로 표시합니다. 0%로 보이지 않습니다. |
| F7 | 점검 줄 보기·누르기 | 점검 줄(카드)에서 현장을 누릅니다. | 필터 범위·선택 월에서 상태가 "점검"인 현장을 공정차이가 작은 순(같으면 현장 ID 순)으로 줄 세웁니다. 한 줄에 현장 ID·이름, 계획·실제 공정률, 공정차이, 기성률을 보여줍니다. 누르면 "현장별 비교표" 페이지로 이동해 그 행을 강조하고 기록을 펼칩니다. | 2026-09 전체: ① D 계획 86.5% / 실제 75.8% / -10.7pp / 기성률 69.4% ② I -7.6pp ③ K -5.4pp. | 점검 현장이 없으면 "점검 대상 없음" 안내를 보여줍니다. 누른 현장이 비교표에 없으면(범위가 바뀐 경우) 비교표 맨 위에서 열고 안내합니다. |
| F8 | 현장별 비교표 보기 | "현장별 비교표" 탭을 누르거나 첫 화면의 표를 봅니다. | 필터 범위의 현장을 표로 만듭니다. 열: 상태·현장 ID·현장명·지역·유형·당월 주요 공종·계약금액·누적기성액·기성률·당월기성액·계획공정률·실제공정률·공정차이. 정렬은 공정차이가 작은 순입니다(같으면 현장 ID 순). 표 아래에 합계·가중평균 행을 둡니다. | 2026-09 전체: 12행, 맨 위 D(점검). 표 위에 "정상 6 · 주의 3 · 점검 3"을 보여줍니다. | 자료가 없으면 표 대신 안내를 보여줍니다. 당월기성액을 못 구하는 칸은 "계산 불가"입니다. |
| F9 | 상황·대응 기록 펼치기 | 행 오른쪽 "펼치기"를 누릅니다. 다시 누르면 접힙니다. | 같은 페이지 안에서 그 행 아래에 3칸을 엽니다: ① 공사기간(착공일~계약상 준공일) ② 기록된 상황(issueSummary)과 특이사항 분류 ③ 기록된 대응 계획(actionPlan). 여러 행을 동시에 펼칠 수 있습니다. | 예: 2026-09 D → 2024-09-02 ~ 2027-02-28 / "골조 자재 공급 정상화 후 작업면 추가 운영 중. 최근 누적 공정차이는 줄고 있으나 지연이 남아 있음." / "층별 작업 순서와 투입 인원을 주간 단위로 확인하고 미달 구간 보완." | 기록 칸이 비어 있으면 "기록 없음"이라고 씁니다(가져오기에서 빈 값은 이미 거부하므로 거의 없습니다). 기록은 "기록된 상황"·"계획된 대응"이라는 이름으로만 쓰고 원인 확정·완료로 바꾸지 않습니다. |
| F10 | 계획·실제 공정률 추이 보기 | (보기만 합니다. 점이나 선에 마우스를 올리면 그 월 값을 봅니다.) | 필터 범위로 시작 월(2025-10)~선택 월까지 매월 따로 가중 계획·가중 실제 공정률을 계산해 두 선으로 그립니다. 선택 월을 강조합니다. | 2026-09 전체: 12개월 선. 9월 계획 73.2%·실제 71.2%. 한 현장을 고르면 그 현장만의 선입니다. | 월별 행이 빠진 달은 선을 잇지 않고 "자료 없음"으로 표시합니다. 자료가 아예 없으면 차트 대신 안내를 보여줍니다. |
| F11 | 월별 기성 막대 보기 | (보기만 합니다. 막대에 마우스를 올리면 당월·누적을 함께 봅니다.) | 같은 범위·기간으로 매월 "당월기성액"을 막대로 그립니다. 누적기성액은 막대 옆 보조 글자로만 따로 씁니다. 두 값을 더하거나 서로 대신하지 않습니다. | 2026-07 당월 29,373.6 / 누적 364,718.5, 2026-08 당월 30,466.2 / 누적 395,184.7, 2026-09 당월 28,878.7 / 누적 424,063.4. | 첫 달 2025-10은 막대 없이 "계산 불가"를 씁니다. 범위 안 현장 중 하나라도 전월 값이 없으면 그 달은 "계산 불가"입니다. 당월기성액 0.0은 정상값이라 0.0으로 표시합니다. |
| F12 | 자료 가져오기 | 파일 고르기(또는 끌어 놓기) → 검사 결과·미리보기 확인 → "전체 교체" 또는 "취소"를 누릅니다. | 브라우저에서 CSV(UTF-8, BOM 허용)·JSON을 읽고 검사합니다(3장 "가져오기 검사 규칙"). 통과하면 행 수·현장 수·월 범위와 앞 5행 미리보기(계산된 기성률·공정차이·상태·당월기성액 포함)를 보여줍니다. "전체 교체"를 누를 때만 자료를 통째로 바꾸고, 바꾼 뒤 필터를 초기화합니다. | 정상 CSV → "144행·12개 현장·2025-10~2026-09, 오류 0". 교체 뒤 CSV와 JSON을 차례로 가져와도 144행입니다. | 오류가 하나라도 있으면 교체 버튼을 막고 오류를 표로 보여줍니다(행 번호·열 이름·값·이유, 처음 20건). "지금 자료는 그대로 유지됩니다"를 함께 씁니다. 취소·다른 파일 선택 시에도 지금 자료는 그대로입니다. |
| F13 | CSV 내보내기 | 상단 "CSV 내보내기"를 누릅니다(현황 요약·비교표 화면). | 필터 범위의 행을 CSV로 만들어 내려받습니다. 원본 15열 뒤에 기성률(%)·공정차이(pp)·상태·당월기성액(백만원) 열을 더합니다. UTF-8 BOM으로 저장해 엑셀에서 한글이 깨지지 않게 합니다. 숫자는 쉼표 없이 단위 그대로 씁니다. | 예: 2026-09 D → 헤더 + 데이터 1행. 인천+공동주택 → 2행. 2025-10 전체 → 당월기성액 열이 모두 "계산 불가". | 범위에 자료가 없으면 버튼을 막고 "내보낼 자료가 없습니다"라고 알려줍니다. 파일 만들기에 실패하면 "CSV를 만들지 못했습니다. 다시 눌러 주세요"를 보여주고 화면은 그대로 둡니다. |
| F14 | AI에게 질문하기 | 질문을 쓰거나 예시 질문을 눌러 채운 뒤 "질문 전송"을 누릅니다. | 서버가 지금 범위의 질문·원문 기록·계산된 지표를 Gemini에 보냅니다(4장 "AI에 보내는 자료"). 답변을 받아 보여줍니다. 계산은 프로그램이 하고 AI는 설명만 합니다. | 상단에 지금 범위(기준 월·지역·유형·현장)를 보여줍니다. 답변에는 기준 월·현장 ID·근거 숫자·참고한 기록 필드를 함께 씁니다. 예시 질문: "D가 늦어진 원인과 대응은?", "점검 현장은 어디인가요?", "J의 7월 기성은 왜 늘지 않았나요?" | 질문이 비어 있으면 전송 버튼을 막습니다. 기다리는 동안 "답변 기다리는 중"을 보여줍니다. 키 없음·한도 초과·시간 초과·연결 실패는 "AI 연결 실패"와 이유 한 줄을 보여주며, 대시보드·CSV는 계속 쓸 수 있다고 안내합니다. 자료에 없는 질문(실제 준공일·미수금·범위 밖 월·현장)은 "자료 없음"으로 답합니다. |
| F15 | 범위 바뀔 때 AI 답변 지우기 | 월·지역·유형·현장 중 하나를 바꿉니다(또는 필터 초기화·자료 교체). | 이전 질문·답변을 지웁니다. 답변을 기다리는 중에 범위가 바뀌면 그 요청의 응답을 버리고 새 범위에 표시하지 않습니다. | 상단 범위 표시가 새 범위로 바뀌고 대화 칸이 비어 있습니다. | 늦게 도착한 이전 범위의 응답은 화면에 나타나지 않습니다. |
| F16 | 화면 이동·처음 열기 | 상단 메뉴(현황 요약·현장별 비교표·자료 가져오기·AI에게 묻기)를 누릅니다. | 같은 앱 안에서 화면을 바꿉니다. 필터와 가져온 자료는 화면을 옮겨도 유지됩니다. 처음 열면 자료가 없으므로 "자료 없음" 상태를 보여주고 "자료 가져오기"로 안내합니다. | 가져오기 전: 큰 숫자·표 자리에 "자료를 먼저 가져와 주세요". 가져온 뒤: 2026-09 전체 현황. | 새로고침하면 가져온 자료가 사라지고 다시 "자료 없음" 상태가 됩니다(이번 범위의 정해진 동작). 이때 "새로고침하면 파일을 다시 가져와야 합니다"를 안내합니다. |

## 2. 역할별 표

| 역할 | 맡는 일 | 맡지 않는 일 |
|---|---|---|
| 사용자 (본사 공무팀 담당자) | 파일 고르기, 가져오기 승인·취소, 월·지역·유형·현장 선택, 행 펼치기, CSV 내려받기, AI 질문 입력 | 숫자 직접 계산, 상태 판정, 자료 수정 |

## 6. 계산 규칙 표

모든 예시는 `data/검산표.md`의 숫자입니다. 계산은 반올림 없이 끝까지 한 뒤, 표시할 때만 소수 첫째 자리로 반올림합니다. 소수 오차를 막기 위해 입력값(소수 첫째 자리)은 10배 한 정수로 계산합니다. (AI 결정)

| 항목 | 계산 방법 | 예시 (검산표 숫자) |
|---|---|---|
| 현장 공정차이 | 실제 공정률 - 계획 공정률 (pp) | D 2026-09: 75.8 - 86.5 = -10.7pp |
| 상태 | 0pp 이상 정상 / -5pp 초과 0pp 미만 주의 / -5pp 이하 점검. 특이사항 분류(issueCategory)로 정하지 않음 | 계획 70·실제 70 → 정상, 실제 65.1 → 주의(-4.9pp), 실제 65 → 점검(-5.0pp) |
| 점검 순위 | 점검 현장만, 공정차이 오름차순, 같으면 현장 ID 오름차순 | 2026-09: D(-10.7) → I(-7.6) → K(-5.4) |
| 현장 기성률 | 누적기성액 / 계약금액 × 100 | D: 50,384.4 / 72,600 = 69.4% |
| 전체 기성률 | 필터 범위의 선택 월 누적기성액 합계 / 같은 범위 계약금액 합계 × 100 | 2026-09 전체: 424,063.4 / 630,700 = 67.2% |
| 전체 계획·실제 공정률 | 현장 계약금액 × 해당 공정률의 합 / 계약금액 합계 (가중평균) | 2026-09: 73.2% · 71.2% |
| 전체 공정차이 | 반올림 전 가중 실제 - 반올림 전 가중 계획 (화면에 보이는 반올림 값끼리 빼지 않음) | 2026-09: -2.0pp |
| 전체 상태 표시 | 전체 공정차이에도 같은 상태 기준을 적용해 글자·색을 표시 (AI 결정) | -2.0pp → 주의 |
| 당월기성액 (현장) | 이번 달 누적기성액 - 바로 전월 누적기성액. 전월 행이 없으면 계산 불가(null). 0이나 누적액으로 대신하지 않음 | D 2026-09: 3,339.6 / 2025-10: 계산 불가 |
| 당월기성액 0.0 | 누락이 아닌 정상값. "계산 불가"와 다르게 표시 | J 2026-07: 26,308.8 - 26,308.8 = 0.0 |
| 당월기성액 (전체) | 범위의 모든 현장에 전월 값이 있을 때만 현장별 차액을 합산. 하나라도 없으면 계산 불가 | 2026-09 전체: 424,063.4 - 395,184.7 = 28,878.7 / 2025-10: 계산 불가 |
| 누적값과 당월값 구분 | 누적기성액·누적 공정률은 "그 달 말까지"의 값, 당월기성액은 "그 달 한 달 동안 늘어난 금액". 월별 누적액을 여러 달 합쳐 총액으로 쓰지 않음. 수금액·미수금은 자료에 없으므로 누적기성액을 수금액처럼 쓰지 않음 | 2026-08 누적 395,184.7 → 2026-09 누적 424,063.4 (이 둘의 차이가 당월 28,878.7) |
| 추이 | 선택한 지역·유형·현장 범위로 매월 따로 집계(월마다 위 식 적용). 시작 월~선택 월까지만 표시 | 2026-09 전체: 2025-10 가중 계획 19.4% → 2026-09 73.2% (12개월) |
| 월별 상태 내역 | 범위의 월별 정상·주의·점검 곳 수 | 2026-09: 정상 6·주의 3·점검 3 |
| 비교표 합계 행 | 선택 월 한 달만의 계약금액·누적기성액 합계와 가중 공정률(위 식). 여러 달을 합치지 않음 | 2026-09: 630,700 / 424,063.4 / 67.2% / 73.2% |
| 지역·유형 필터 예 | 필터 범위로 같은 식을 적용 | 2026-09 인천: 185,100 / 113,211.9 = 61.2% (A·G 2곳) |

| 표시 단위 | 금액은 백만원(천 단위 쉼표), 비율은 %, 차이는 pp, 모두 소수 첫째 자리. 양수는 +를 붙임 | 424,063.4백만원, 67.2%, -2.0pp |

## 7. 시안과 다르게 정한 것 (확인이 필요합니다)

시안은 배치와 분위기를 따르되, 실습조건·PRD·자료에 없는 내용은 넣지 않습니다.

| 시안에 있는 것 | 이번에 하는 것 | 이유 |
|---|---|---|
| 시안 속 현장명·지역·금액·기성액 | 모두 `data/` 자료의 값으로 대체 | 시안 숫자는 자료와 다릅니다. 예: 시안 월별 기성 "7월 27,105.2"는 검산표 7월 당월기성액 29,373.6과 다릅니다. |
| 기성률 카드의 "+4.5%p"와 당월 카드의 "전월 대비 +2,572.3" | 넣지 않음. 큰 숫자 4개는 값과 누적/계약금액·계획 값만 보여줌 | 전월 대비 계산은 정해진 기준이 없고, 시안 값은 검산표와 맞지 않습니다(9월 당월은 8월보다 1,587.5 적음). |
| 비교표의 "상태 칩 필터(전체·정상·주의·점검)"와 정렬 기준 바꾸기 | 넣지 않음. 상태별 곳 수만 글자로 보여주고, 정렬은 공정차이 오름차순 고정 | 실습조건에 없는 기능입니다. 필요하시면 추가 여부를 알려 주세요. |
| 비교표 CSV 버튼 2개("선택 1건"·"전체 12건 일괄") | "CSV 내보내기" 1개(현재 필터 범위) | PRD 5번: 지금 고른 범위와 같은 범위를 내보냅니다. 1건만 받으려면 현장 필터를 씁니다. |

| 펼침 카드의 "이 현장에 대해 AI에게 묻기" 버튼 | 넣지 않음 | PRD 질문 5에서 점검 줄을 누르면 "비교표로 이동"을 고르셨습니다. AI로 이동하는 버튼은 선택하지 않은 방식이라, 원하시면 알려 주세요. |
