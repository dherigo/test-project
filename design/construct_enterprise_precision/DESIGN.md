## Brand & Style

### Brand Personality & Core Mood
본 시스템은 대형 건설 엔터프라이즈의 본사 공무팀 및 현장 관리 임원진을 위한 고신뢰도 공정·기성 통합 관제 UI입니다. 브랜드의 핵심 가치는 **신뢰성(Trust)**, **엄격한 정확도(Precision)**, **신속한 상황 인지(Operational Clarity)**입니다. 

화려한 시각적 효과나 장식성을 철저히 배제하고, 장시간 복잡한 수치와 공정 일정을 검토하는 실무자의 시각 피로도를 낮추는 **엔지니어링 중심의 Corporate / Modern 미니멀리즘**을 지향합니다. 구조적 명료함과 데이터 간의 콘트라스트를 최우선으로 하여 현장의 비정상 징후(공정 지연, 기성 미수금 누적 등)를 단 1초 만에 식별할 수 있는 산업용 계측기 수준의 사용성을 제공합니다.

### Target Audience & Use Case Context
- **주 타겟**: 건설 본사 공무팀, 외주·기성 관리자, 경영진 및 현장 소장.
- **주 사용 환경**: PC 웹 데스크톱(FHD 1080p 및 QHD 환경 고정), 다중 모니터 환경에서 대량의 테이블과 시각화 지표를 실시간 검토.
- **감정적 반응**: "안정적이고 견고하다", "데이터의 위계가 직관적이라 실수가 발생하지 않는다", "정확하고 권위가 느껴진다".

## Colors

본 시스템의 컬러 팔레트는 데이터의 즉각적인 인지와 엄격한 위계 분리를 위해 세심하게 보정된 고대비 엔터프라이즈 팔레트를 사용합니다.

### 기본 팔레트 구성
- **Primary (`#0F172A`)**: Slate Navy Deep. 글로벌 헤더, 핵심 액션, 타이틀에 적용하여 최고 수준의 안정감과 권위를 부여합니다.
- **Secondary (`#1E293B`)**: Slate Navy Medium. 사이드바, 섹션 헤더, 주요 상호작용 요소의 기본 바탕으로 활용됩니다.
- **Tertiary (`#2563EB`)**: Construction Blue. 링크, 활성 탭 인디케이터, 데이터 인터랙션 강조에 국소적으로 사용하여 단조로움을 해소합니다.
- **Neutral (`#64748B`)**: 메타데이터 텍스트, 2차 라벨, 서브 보더에 사용되어 데이터 본문과의 뚜렷한 대비를 형성합니다.

### 표면 및 배경 계층 (Surface Hierarchy)
- **Canvas Base**: `#F8FAFC` (Slate 50) - 배경 전체의 반사율을 낮추고 피로도를 완화하는 차분한 베이스.
- **Surface Level 1 (Card/Table)**: `#FFFFFF` (Pure White) - 지표 카드와 테이블 행 등 가독성이 최우선인 영역.
- **Surface Level 2 (Sub-table/Filter Bar)**: `#F1F5F9` (Slate 100) - 필터 컨트롤 바, 테이블 헤더, 아코디언 확장 영역의 배경.
- **Surface Level 3 (Muted Hover)**: `#E2E8F0` (Slate 200) - 테이블 로우 호버 및 비활성 입력창.
- **Border Neutral**: `#CBD5E1` (Slate 300) - 테이블 그리드선 및 컴포넌트 경계선에 사용되어 또렷한 시인성을 확보.

### 상태 표시 토큰 (Status Indicators)
기성 및 공정 진행 상태는 배경과 텍스트의 명도 대비(Contrast Ratio 4.5:1 이상)를 철저히 지켜 원거리에서도 오독이 없도록 짝지어 적용합니다:
- **정상 (Normal / On-track)**: Text `#16A34A` (Green 600) / Background `#DCFCE7` (Green 100) / Border `#86EFAC` (Green 300)
- **주의 (Warning / Pending)**: Text `#D97706` (Amber 600) / Background `#FEF3C7` (Amber 100) / Border `#FCD34D` (Amber 300)
- **점검 / 지연 (Critical / Delayed)**: Text `#DC2626` (Red 600) / Background `#FEE2E2` (Red 100) / Border `#FCA5A5` (Red 300)
- **대기 (Neutral / Planned)**: Text `#475569` (Slate 600) / Background `#F1F5F9` (Slate 100) / Border `#CBD5E1` (Slate 300)

## Typography

본 디자인 시스템은 다수의 숫자, 단위, 한글 공종명(토공사, 골조공사 등)이 얽힌 데이터 집약적 환경에 맞춰 글로벌 기준 검증된 **Inter**를 주 서체로 채택하며, 현장 코드 및 PBS(공정분류체계) 표기에는 **JetBrains Mono**를 혼용합니다.

### 수치 데이터 포맷팅 규칙
- **고정폭 숫자 (Tabular Figures)**: 테이블 내 모든 수치 셀과 KPI 카운터는 CSS `font-variant-numeric: tabular-nums;` 속성을 강제 적용하여 자릿수 간 정렬 오차를 원천 방지합니다.
- **금액 표기 규칙**: 엔터프라이즈 건설 기성 특성상 원 단위 대신 `백만원` 단위를 기본 모듈로 표기하며, 천 단위 콤마(`,`)를 필수 적용합니다. (예: `14,850 백만원`)
- **공정률 및 차이 표기**:
  - 누적 공정률 및 달성률은 소수점 첫째 자리까지 표기합니다. (예: `84.3%`)
  - 계획 대비 실적 차이는 포인트 증감 `pp` 표기를 원칙으로 합니다. (예: `-2.4%p` 또는 `+1.8%p`)
  - 양수 변화는 녹색 계열, 음수 지연은 적색 계열의 볼드 폰트를 매핑합니다.

## Layout & Spacing

본 시스템은 **PC 웹 데스크톱(1440px ~ 1920px+)** 환경에 최적화된 **12컬럼 고정 패딩 플루이드 그리드** 체계를 사용합니다. 브라우저 뷰포트 전체 폭을 기능적으로 활용하여 수평 스크롤 없이도 방대한 공정 테이블이 한눈에 파악되도록 설계되었습니다.

### 뷰포트 구성 모델
- **GNB (Global Navigation Bar)**: 높이 `56px`의 상단 고정 바. 현장 셀렉터, 본사/현장 전환, 알림 센터가 상주.
- **Filter & Search Bar**: 높이 `48px`의 2단 서브 헤더. 공구, 기간(12개월 슬라이스), 공정 상태 다중 필터를 집약 배치.
- **Main Viewport Layout**:
  - 상단 KPI 영역: 4열 균등 분할 그리드 (`col-span-3` x 4개).
  - 중단 차트 & 분석 영역: 계획 대비 기성 누적 12개월 추이 차트 (`col-span-8`) + 주요 공정 리스크 요약 패널 (`col-span-4`).
  - 하단 마스터 테이블: 12열 전폭(`col-span-12`)의 고집적 데이터 그리드.

### 밀도(Density) 규칙
엔터프라이즈 공무 업무의 특성상 과도한 여백은 스크롤 부하를 초래하므로 밀도 높은 컴팩트 리듬을 적용합니다:
- 테이블 행 높이(Row Height): 기본 `40px`, 컴팩트 뷰 `32px`.
- 데이터 셀 패딩: 수직 `space-xs` (4px), 수평 `space-md` (12px).
- 카드 내부 패딩: `space-lg` (20px).

## Elevation & Depth

본 시스템은 그림자(Shadow)를 통한 공간 분리를 최소화하고, **선명한 테두리선(Crisp Borders)**과 **정교한 표면 명도(Tonal Hierarchy)**를 통해 시각적 깊이를 만듭니다. 흐릿한 그림자는 수치 데이터 판독 시 눈의 착시와 피로를 유발하기 때문입니다.

### 표면 계층 및 테두리 구조
- **평면 기본 구조 (Zero-Elevation Default)**: 대시보드의 모든 카드, 컨테이너, 필터 바는 그림자 없이 `1px solid #CBD5E1`의 구조적 테두리를 사용하여 캔버스와 분리됩니다.
- **포커스 및 선택 상태**: 활성화된 카드나 행은 외곽선 두께를 `2px`로 전환하거나 `#2563EB` 링을 적용하여 명확성을 극대화합니다.
- **부유 요소 (Overlays & Menus)**: 드롭다운 셀렉터, 툴팁, 모달 창에 한해서만 매우 절제된 저확산 섀도우를 국소 적용합니다:
  - Dropdown Menu: `box-shadow: 0 4px 6px -1px rgba(15, 23, 42, 0.08), 0 2px 4px -2px rgba(15, 23, 42, 0.06); border: 1px solid #94A3B8;`
  - Chart Tooltip: `box-shadow: 0 10px 15px -3px rgba(15, 23, 42, 0.12); background: #0F172A; color: #FFFFFF;`

## Shapes

본 시스템의 형상 언어는 **Soft (레벨 1)**을 채택합니다. 토목·건축 현장의 단단함과 규격화된 도면의 직선미를 반영하여 라운드 반경을 최소화합니다.

### 라운드 토큰 적용 지침
- **기본 버튼, 텍스트 필드, 셀렉트 박스**: `4px` (`rounded-sm`). 날렵하고 정돈된 인상을 주며 정렬 기준선을 명확히 유지합니다.
- **데이터 카드, 대시보드 패널, 모달**: `6px` (`rounded-md`). 넓은 면적의 시각적 긴장감을 자연스럽게 완화합니다.
- **상태 태그 / 뱃지 (Chips)**: `3px` (`rounded-xs`). 텍스트 높이에 밀착하여 테이블 행 내부의 수직 정렬을 방해하지 않습니다.
- **완전 둥근 형태(Pill-shaped) 배제**: 캐주얼한 모바일 앱의 뉘앙스를 주는 필 형태는 절대 사용하지 않습니다.

## Components

### 1. KPI Stat Cards (핵심 실적 지표)
- **구조**: 최상단 4분할 배치 (전체 공정률, 금월 기성액, 누적 수금률, 미수/지연 리스크).
- **스타일**: 백색 배경, `1px solid #CBD5E1` 보더. 상단에 12px 캡션 라벨, 중앙에 32px Bold 볼륨 수치(`font-variant-numeric: tabular-nums`), 하단에 전월 대비 증감률 뱃지(`+1.4%p`) 및 계획 대비 달성률 프로그레스 바(높이 4px) 배치.

### 2. High-Contrast Data Table (마스터 공정·기성 테이블)
- **헤더**: 배경색 `#F1F5F9`, 텍스트 `#334155` (12px, Semi-bold). 컬럼별 소팅 인디케이터 상시 노출.
- **셀 데이터 정렬**: 텍스트(공종명, 현장명)는 좌측 정렬, 상태 태그는 중앙 정렬, 모든 수치(공정률, 금액)는 **우측 정렬**을 엄격히 적용.
- **보더**: 각 셀 간 수직 구분선(`border-r: 1px solid #E2E8F0`)을 두어 복잡한 숫자 열 간의 시선 간섭을 방지.
- **얼룩말 패턴(Zebra Striping)**: 짝수 행에 `#F8FAFC`를 적용하여 가로 줄 읽기 가독성을 극대화.

### 3. Accordion Sub-Rows (공종별 내역 행 확장 패턴)
- 테이블 좌측에 펼침 아이콘(`Chevron Right` / `Chevron Down`) 배치.
- 행 클릭 시 마스터 행 하단에 레벨 2 인덴트 서브 테이블이 펼쳐지며, 배경은 `#F8FAFC`로 톤 다운되고 좌측에 `3px solid #2563EB` 인디케이터 라인이 이어져 소속 종속 관계를 즉시 전달.

### 4. 12-Month Trend Line/Bar Chart (계획 대 실적 추이)
- **차트 캔버스**: 12개월(1월~12월)을 가로축에 일괄 배치.
- **계획선**: `#94A3B8`의 파선(Dashed line).
- **실적 막대**: `#0F172A` (Slate Navy)의 솔리드 바.
- **현재 월(당월) 인디케이터**: 당월 컬럼 영역에 옅은 블루 오버레이 밴드(`#EFF6FF`)를 적용하여 과거 실적과 미래 계획의 분기점을 명시.

### 5. Status Badges & Chips
- 텍스트 11px Medium, 상하 패딩 2px, 좌우 패딩 6px.
- 점검(지연) 태그의 경우 단순 텍스트뿐만 아니라 직경 6px의 채워진 점(Dot Indicator)을 선두에 배치하여 색각 이상자도 인지 가능하도록 이중 피드백 제공.

### 6. Filter Controls & Date Selectors
- 일관된 32px 컴팩트 높이.
- 회계연도 선택 드롭다운, 분기 탭 스위치, 본부/현장 복합 셀렉터가 조합된 툴바 형태로 상단에 고정.
- 초기화 버튼 및 엑셀 다운로드(`Excel Export`) 버튼을 우측 끝에 영구 고정 배치.
